# Инструкция менеджера — управление B2B-партнёрами

Практическое руководство по работе с партнёрами в админке Shopify: создание
аккаунтов, скидки, пароли, заказы. Не требует кода.

> Ключевое правило доступа: партнёр видит оптовый каталог и цены **только если
> у его аккаунта есть тег `wholesale`** (строчными буквами). Нет тега → видит
> сайт как гость, даже если залогинен.

---

## 1. Создать партнёра (обычный случай, есть email)

1. **Admin → Customers → Add customer**.
2. Заполни First/Last name, **Email**, телефон, адрес.
3. В блоке **Tags** добавь: `wholesale` (доступ к опту). Если используешь
   статусы — можешь добавить `pending` до одобрения.
4. Save.
5. **Метафилды** (блок Metafields внизу карточки клиента) — задай:
   - `custom.discount_tier` → один из: `standard` / `silver` / `gold` / `platinum`
   - `custom.discount_percentage` → число, напр. `15`
   - `custom.shop_name` → название магазина партнёра (показывается в топбаре «Welcome, …»)
   - `custom.vat_number`, `custom.company_name` — по необходимости
6. Нажми **Send account invite** — клиенту уйдёт письмо «задайте пароль».

> Если метафилдов нет в списке — их надо один раз создать:
> Settings → Custom data → Customers → Add definition (namespace `custom`,
> ключи как выше). См. SHOPIFY-SETUP.md.

---

## 2. Создать партнёра БЕЗ email (клиенты 50+, нет почты)

Shopify-логин всегда требует email-идентификатор, но он **не обязан быть
настоящей почтой клиента**. Делаем «технический email», который читаешь ТЫ —
это нужно, чтобы потом можно было сбрасывать пароль (см. раздел 4).

1. Заведи себе один почтовый ящик-приёмник, например `partneri@leatherparfum.cz`
   (или catch-all на домене, или Gmail с алиасами `tvojapochta+partner1@gmail.com`).
2. **Add customer** → в Email впиши уникальную строку на этом ящике, удобно — по телефону:
   `420777123456@leatherparfum.cz` (или `partneri+420777123456@gmail.com`).
3. В **Phone** впиши реальный номер клиента (для связи).
4. Tags: `wholesale` + метафилды (раздел 1, шаг 5).
5. Save → **Send account invite**. Письмо «задайте пароль» придёт НА ТВОЙ ящик.
6. Открой письмо, перейди по ссылке, **задай пароль** за клиента.
7. Сообщи клиенту его логин (эту email-строку) и пароль — по телефону/в мессенджере.

Клиент входит на `/pages/partner-login` по выданным email-строке и паролю.
Свою почту он не вводит и письма ему не нужны.

> Совет: храни список «телефон → логин-строка» в отдельной таблице, чтобы
> быстро находить аккаунт по звонку.

---

## 3. Одобрить / заблокировать партнёра

- **Одобрить заявку:** открой клиента → Tags → добавь `wholesale` (и убери
  `pending`, если ставил). Сразу появляется доступ к ценам.
- **Заблокировать:** убери тег `wholesale` (можно добавить `b2b-blocked` для
  пометки). Клиент снова станет «гостем».
- Если регистрацию ведёт **Massy** — тег `wholesale` может ставиться им
  автоматически при одобрении. Проверь в настройках Massy, какой тег он ставит;
  тема ждёт ровно `wholesale`.

---

## 4. Партнёр потерял пароль / звонит восстановить

**Пароль увидеть нельзя** (зашифрован). Можно только сбросить. Два пути:

**A. Клиент с настоящим email:**
1. Скажи ему открыть `/pages/partner-login` → «Forgot password?» → ввести email.
2. Ему придёт ссылка на сброс. Готово.
   (Или ты на карточке клиента → ⋯ → можешь повторно отправить account invite.)

**B. Клиент с «техническим email» (раздел 2) — звонит тебе:**
1. Найди его аккаунт по телефону (в твоей таблице или поиском в Customers по Phone).
2. Открой `/pages/partner-login` (или `/account/login`) → «Forgot password?» →
   введи его **email-строку** (`420777...@leatherparfum.cz`).
3. Письмо со ссылкой придёт **на твой ящик-приёмник**.
4. Перейди по ссылке, задай новый пароль.
5. Продиктуй клиенту новый пароль по телефону.

> Именно поэтому в разделе 2 технический email должен быть на ящике, который
> читаешь ты. Если завести фейковый адрес на несуществующем домене — сброс
> станет невозможен, аккаунт придётся пересоздавать.

---

## 5. Скидочный тир партнёра

Цена партнёра = WSP × (1 − discount_percentage/100). Управляется метафилдами:
1. Customers → клиент → Metafields.
2. `custom.discount_tier` = `silver`/`gold`/`platinum` (или `standard` без скидки).
3. `custom.discount_percentage` = число процентов.
4. Save. Изменения сразу видны партнёру в каталоге, корзине и на товаре.

> Не задавай скидку тегами И метафилдами одновременно — источник правды один:
> **метафилды**.

---

## 6. Заказы и проформа-инвойс

1. Партнёр оформляет заказ → он попадает в **Admin → Orders** со статусом
   **Payment pending** (оплата по инвойсу, без карты).
2. В заказе:
   - блок **Notes** → «PO Number: … / Notes: …» (что партнёр ввёл в корзине);
   - **Additional details** → атрибуты `po_number`, `order_notes`.
3. Проверь наличие товара, при необходимости отредактируй заказ.
4. **More actions → Print with Order Printer → Proforma Invoice** → отправь
   партнёру PDF (см. order-printer/proforma-invoice.liquid).
5. После оплаты переводом — отметь заказ оплаченным (Mark as paid) и отгружай.

---

## 7. Частые проблемы

| Симптом | Причина | Решение |
|---|---|---|
| Партнёр залогинен, но видит «гостевые» цены и «log in» | нет тега `wholesale` | добавь тег (строчными) |
| В топбаре нет имени магазина | пуст метафилд `custom.shop_name` | заполни его |
| Скидка не применяется | метафилды пустые или `discount_tier = standard` | задай tier ≠ standard и процент |
| Не приходит письмо сброса | технический email на «мёртвом» домене | пересоздай на ящике, который читаешь |
| Каталог без цен у всех | товары без метафилда `custom.wholesale_price` | заполни WSP на товарах (в кронах) |
