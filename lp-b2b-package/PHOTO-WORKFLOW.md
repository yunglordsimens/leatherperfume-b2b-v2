# Фото-пайплайн: съёмка → обработка → сайт

Цель: один раз задать систему, чтобы съёмка, поиск по складу, обработка и
загрузка на сайт были связаны через **один ключ — SKU**, и чтобы результат был
консистентным (одинаковые отступы, фон, тени).

---

## 1. Один ключ на всё — SKU

SKU — единственный идентификатор, который связывает: **физический товар на
складе ↔ карточку в Shopify ↔ файлы фото**. Если у клиента уже есть коды —
используем их; если нет, предложить простую схему:

```
LP-<ТИП>-<ЛИНИЯ>-<ЦВЕТ>[-<ОБЪЁМ>]
напр.  LP-PARF-ELG-50    (парфюм Elegant 50ml)
       LP-WAL-HER-BRN    (кошелёк Heritage, коричневый)
```

- Тип: PARF / WAL (wallet) / BELT / SET …
- Цвет: BRN / BLK / RED … (помним: **каждый цвет = отдельный товар**, схема A).
- Этот SKU клеится на товар/полку → легко найти, что снимать и куда грузить.

## 2. Имена файлов = SKU + индекс

Так Shopify и ты всегда знаете, к какому товару фото:
```
Обычные фото:  LP-WAL-HER-BRN_01.jpg, _02.jpg, _03.jpg …  (_01 = главная)
Спин-кадры:    LP-WAL-HER-BRN_spin_01.jpg … _spin_36.jpg
```
Загрузка в Shopify: имя файла с SKU → можно лить пачкой и матчить к товару.

## 3. Съёмка — рекомендации стрелку (консистентность = меньше обработки)

Главное правило: **консистентность задаётся на съёмке, а не в AI.** Если кадры
сняты одинаково — обработка тривиальна и одинакова.

- **Камера на штативе, не двигается.** Один и тот же объектив, расстояние, высота,
  угол для ВСЕХ товаров (отметить скотчем позиции).
- **Ручные настройки**: фиксированные экспозиция, баланс белого, фокус. Не авто.
- **Ровный свет** (софтбоксы), **бесшовный фон** (белая/серая бумага-фон) —
  тогда вырезание чистое.
- **Серая карта/референс** в первом кадре для одинакового цвета.
- **Одинаковое положение и масштаб** товара в кадре (метки на столе).

### Для спина (поворотный стол у них есть — отлично)
- Стол вращается, **камера и свет неподвижны**.
- **24–36 кадров** на круг (через равные углы), пульт/таймер, без тряски.
- Товар по центру так, чтобы **поддон стола можно было ровно обрезать** сверху —
  или стол с верхом в цвет фона. Поддон в кадре = главная проблема, решается
  кадрированием/фоном на съёмке.

## 4. Обработка — как добиться одинакового результата

### Обычные фото (stills) — да, можно «через AI», но правильно
Секрет одинаковых отступов и фона — **не AI-генерация фона, а вырезание + шаблон**:
1. **Вырезать фон** (AI-каттер).
2. Положить на **фиксированный холст-шаблон**: один размер канваса, товар
   занимает **фиксированный % с одинаковыми полями** → отступы по бокам одинаковые
   у всех. Это и есть ответ на «одинаковые отступы».
3. **Тень** — AI-контактная тень из того же инструмента (для stills выглядит ок).

**Инструмент-рекомендация: Photoroom** (есть **батч + брендовый шаблон**:
фикс. канвас, фикс. поля, авто-тень) — он ровно под твою задачу «одинаковые поля
+ фон + тень пачкой». Альтернативы: Pixelcut, ClippingMagic, или экшены/батч в
Photoshop, если хочешь полный контроль.

### Спин 180/360 — честно: НЕ гнать каждый кадр через AI
- AI обрабатывает каждый кадр **независимо** → фон/тень/обрезка чуть «гуляют» от
  кадра к кадру → при вращении это **дрожит/мерцает**, выглядит дёшево.
- Поэтому: **спин лучше снять чисто** (поворотный стол, бесшовный фон, ровный
  свет) и обрезать **одной и той же рамкой** для всех кадров (одинаковый кроп).
  Реальная мягкая тень на съёмке > попытка налепить фейк-тень покадрово.
- Авто-удаление фона для спина — только если фон идеально ровный И каттер даёт
  стабильную маску; иначе мерцает. Фейк-тень покадрово почти всегда плохо.

**Вывод по AI:** stills — да (каттер + шаблон Photoroom, одинаковые поля). Спин —
нет, ставка на чистую съёмку + единый кроп. Это сэкономит тебе нервы и время.

### Про имеющееся студийное видео
Снятое видео «так себе» (виден поддон, качество среднее) → вытащить кадры и
почистить покадрово = будет мерцать. Лучше **переснять спин** на их поворотном
столе по рекомендациям выше; старое видео — только как референс. Отдельные
stills из семплов на руках — снимай и гони через Photoroom-шаблон.

## 5. Загрузка на сайт
- Stills: имена `SKU_01..` → залить пачкой в товар (главная = _01).
- Спин-кадры: `SKU_spin_01..NN` по порядку → в метафилд `custom.spin_frames`
  (список изображений). Я собираю из них вьюер на странице товара.

## 6. Финишный чек-лист (чтобы закончить)
1. Согласовать SKU-схему с клиентом (или взять их коды).
2. Снять пилот: несколько парфюмов + по 1 товару каждого типа — как эталон сетапа.
3. Прогнать stills через Photoroom (брендовый шаблон: канвас, поля, тень).
4. Спин — снять чисто на поворотном столе; единый кроп; без покадрового AI.
5. Назвать файлы по SKU; залить; спин-кадры → метафилд.

## 7. AI-промпт (релайт/чистка) — заметки

Промпт (релайт, изоляция на белом, центрирование, равные поля, сохранение
деталей) — хорош для «дорогого» вида, но 3 поправки:

- **Достоверность.** AI-релайт может изменить фактуру кожи / логотип / фурнитуру
  даже при «preserve details». Для B2B критично → **всегда сверять с оригиналом**.
  AI-вид — для hero/маркетинга; каталожное фото должно быть правдивым.
- **Центрирование/поля — не на AI** (центрирует «на глаз», поля гуляют). AI только
  релайт/вырезание → потом **фикс-шаблон Photoroom** задаёт точные одинаковые поля.
- **Соотношение `--ar 4:5`, не 3:4** — карточки 4:5, иначе обрежет и поля поедут.

## 8. Шаблон фото на товар (стиль LV: фикс. число и набор кадров)

Один и тот же набор на каждый товар внутри типа = «дорого и чисто».

**Кожа (кошелёк/ремень/сумка) — 5 кадров + спин:**
1. Спереди (закрытый) — `_01` = плитка каталога
2. Сзади — `_02`
3. Деталь 1: фактура/фурнитура (молния, пряжка) — `_03`
4. Деталь 2: логотип/тиснение/строчка — `_04`
5. Развёрнутый/внутри (для кошелька можно раскрытый спереди и сзади) — `_05`(`_06`)
6. Спин 180° — `_spin_01..NN`

**Парфюм — 4 кадра:**
1. Спереди (флакон) — `_01` = плитка
2. Сзади/этикетка — `_02`
3. Деталь: крышка/гравировка/стекло — `_03`
4. С упаковкой / в руке (масштаб) — `_04`

Правила: `_01` всегда чистый пэкшот спереди (ровная сетка); одинаковый порядок и
число в типе; «с рукой» — всегда последним доп-кадром, не первым; все кадры — один
сетап + один Photoroom-шаблон.

## 9. Photoroom-шаблон (точные цифры)

- **Соотношение 4:5**, канвас **2000 × 2500 px** (или 2400 × 3000 для premium-зума).
- **Поля одинаковые**: товар ~80% кадра, поля ~10% со всех сторон. «Воздушнее» (LV):
  товар ~72–75%, поля ~12.5%. В Photoroom: фикс. output size + padding → у всех
  одинаково.
- **Фон чисто белый `#FFFFFF`** (не серый — на фоне сайта #FAFAF9 серый «грязнит»).
- **Тень**: AI-контактная, мягкая, слабая (не «парящая»).
- Export PNG/JPG 90%+; снимать с запасом по краям; сохранить как brand template и
  применять ко всем (и к спин-кадрам — тем же кропом).

## 10. Что можно улучшать, а что нет (достоверность)

**Можно (товар не меняется):** выпрямление/перспектива (Lightroom Auto Upright,
PS, Photoroom); свет/мягкие блики (релайт); цвет/ББ/контраст (серая карта-эталон);
пыль/ворс/временные пятна; подчёркивание **реальной** текстуры (Texture/Clarity +
шарп).

**Нельзя / осторожно:** «чинить» кривизну/мятость самого товара в AI; генерация
или подмена текстуры; сильный AI-релайт, дорисовывающий детали.

**Приём «чинить на сете, а не в AI»:** набить кошелёк/сумку (держит форму),
отпарить кожу, поставить ровно/подпереть, выровнять строчку, хорошо выставить свет
— реальный товар выглядит идеально и фото правдивое. Hero на главной — можно
смелее с AI; каталожная плитка — максимально правдивая.

## 11. Замеры (размеры)
Метафилд `custom.dimensions` (текст, напр. «12 × 9 × 2 см») → вывод на странице
товара отдельной строкой. Просто замерить и вписать, линейку снимать не надо.
