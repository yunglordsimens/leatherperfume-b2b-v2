# Leather Parfum B2B — Project Package

Этот пакет — **single source of truth** для проекта B2B-портала Leather Parfum на Shopify Dawn. Любой AI-ассистент или человек, открывая этот репо, должен прочитать этот файл и `/docs/README.md` первыми, прежде чем что-либо делать.

## Что это за проект

B2B wholesale portal для нишевой парфюмерии и кожаных изделий. Тема — Shopify Dawn, кастомизированная под B2B-флоу. Кастомеры — верифицированные ритейл-партнёры (бутики, концепт-стораны).

- **Локации:** Прага (склад) → клиенты в EU + Vietnam
- **Языки:** EN, CS, VI
- **Валюта:** CZK (только)
- **Auth:** Massy B2B app (НЕ Shopify B2B)
- **Checkout:** кастомный flow → генерация инвойса (Shopify checkout НЕ используется)
