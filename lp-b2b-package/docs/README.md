## Как обновлять документацию

После любых значимых изменений в репо:
- Запись в `PROGRESS.md` → секция "Session Log"
- Если новый баг → строчка в `BUGS.md`
- Если архитектурное решение → строчка в `ARCHITECTURE.md` или закрытие пункта в `DECISIONS.md`
- Если новая фича в скоупе → строчка в `MVP-CHECKLIST.md` или `REQUIREMENTS.md`

Документация и код должны идти вместе, иначе через неделю опять начнётся «AI забывает контекст».
