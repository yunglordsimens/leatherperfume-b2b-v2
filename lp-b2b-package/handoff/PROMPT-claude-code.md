## Правила для Claude Code в этом проекте

1. **Не работай с веткой `main`.** Все правки идут в `claude/react-to-shopify-hero-lfeDP-deepseek`.
2. **Не предлагай Tailwind, React, или внешние CSS** в Liquid-теме. Inline CSS only (см. ARCHITECTURE).
3. **Не используй Shopify Checkout** — кастомный flow через `/pages/thank-you`.
4. **Проверяй `customer.tags contains 'wholesale'`** на всех приватных страницах.
5. **WSP метафилд = CZK display value**, не cents. Если видишь `/ 100` рядом с `wholesale_price` — это баг.
6. **После любого значимого изменения** — обнови `/docs/PROGRESS.md` Session Log с описанием что сделано.
7. **Если нашёл баг** — добавь в `/docs/BUGS.md` строчку.
8. **Если архитектурное решение** — сначала спроси пользователя, потом обнови `/docs/ARCHITECTURE.md` или закрой пункт в `DECISIONS.md`.

## Когда передавать обратно в чат с CL

Возвращайся к Claude в чате когда:
- Нужно принципиальное решение пользователя (что-то из DECISIONS.md)
- Видишь конфликт между документацией и кодом — нужна синхронизация
- Задача требует большого ресёрча/планирования (это лучше делать в чате до кода)
- Закончил большой блок работы — нужно зарегистрировать в PROGRESS

## Когда подключать DeepSeek

Передавай задачу в DeepSeek (через копипаст из чата) когда:
- Нужен глубокий code review
- Дебаг сложного бага
- Архитектурный рефакторинг
- Анализ больших кусков Liquid/JS

## Когда подключать Gemini

Только для:
- Дизайн-вопросы
- Новые React-макеты (если нужны страницы которых нет в `/mockups`)
- Визуальная критика существующих компонентов
