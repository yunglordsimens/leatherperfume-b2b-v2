# Prompt for Gemini

Gemini в этом проекте отвечает за дизайн. У неё уже есть готовый React-макет в `/mockups`. Дальше — точечные дизайн-задачи.

---

## Стартовое сообщение для Gemini (в начале новой сессии)

```
Контекст: я делаю B2B-портал для Leather Parfum (нишевая парфюмерия + кожаные изделия)
на Shopify Dawn. Сайт закрытый, для верифицированных ритейл-партнёров.

Дизайн-направление:
- Editorial luxury, не яркие цвета, premium-сдержанный
- Палитра: stone/amber (земляная)
- Шрифт заголовков: Yeseva One
- Типографика во главе угла
- 3 языка: EN / CS / VI
- 1 валюта: CZK

У меня уже есть готовый React-макет лендинга на 11 блоков (твоя предыдущая работа).
Сейчас нужно:
[конкретная задача]
```

---

## Когда нужен Gemini

- ✅ Новый дизайн страницы которой нет в `/mockups`:
  - Кастомный checkout
  - Страница `/pages/thank-you`
  - Дашборд аккаунта (dashboard, orders, reorder, invoice download)
  - PDP (если решим что Dawn-дефолт не подходит)
  - 404 страница
  - Apply-for-partnership лендинг (отдельно от формы Massy)

- ✅ Визуальный фикс существующего блока:
  - "Перерисуй Hero чтобы было больше дыхания"
  - "Сделай альтернативный вариант WholesalePackages где 3 пакета, не 2"

- ✅ Дизайн-критика реализованного Liquid против исходного React:
  - "Вот скрин live-страницы и оригинальный JSX — что разъехалось"

## Когда НЕ надо Gemini

- ❌ Логика, бизнес-правила, скидки, MOQ, гейтинг — это к DS / CC
- ❌ Перевод React → Liquid — это к CC (он будет читать `.jsx` как референс)
- ❌ Архитектурные решения — это к US, CL, и DECISIONS.md
- ❌ Дебаг — это к DS

## Формат вывода от Gemini

Gemini выдаёт **React-макет в `.jsx` формате**, совместимый с тем что уже в `/mockups/components/`:

- Использует Tailwind CSS classes
- Использует `lucide-react` иконки
- Принимает `highContrast`, `getHeadingSize`, `getBodyTextSize` props (см. существующие компоненты)
- Functional component, default export

После получения нового макета:
1. CL сохраняет его в `/mockups/components/<NewName>.jsx`
2. CL добавляет строчку в `/mockups/SECTIONS-MAP.md`
3. CL добавляет в `/docs/PROGRESS.md` Session Log

## Шаблон постановки задачи

```
Привет Gemini. Контекст уже у тебя (см. сообщение выше).

Задача: <одно предложение>

Бизнес-контекст:
- <что эта страница/блок должна делать>
- <кто её увидит — гость / pending / wholesale>

Дизайн-ограничения:
- Палитра: stone-900, amber-700, amber-50 (как в существующих компонентах)
- Шрифт: font-serif для заголовков, sans для body
- Tailwind CSS

Референсы которые надо учесть:
- /mockups/components/<существующий компонент>.jsx — для консистентности

Что отдать на выходе:
- .jsx файл готовый к сохранению в /mockups/components/
- Принимающий стандартные props (highContrast, getHeadingSize, getBodyTextSize, и т.п.)
- Без зависимостей кроме React + lucide-react + Tailwind
```
